# UNO 大作战 · 玩法演示动画短片设计

日期：2026-07-31
状态：已获用户批准（方案 + 视觉 + 故事板）

## 目标

制作一段约 30 秒的动画短片，演示「UNO 大作战」的核心玩法，输出为 MP4 视频文件，带解说字幕，视觉风格与介绍 PPT 一致（Claude / Anthropic 美学 + UNO 卡牌）。

## 已确认的决策

- **交付形态**：MP4 视频文件
- **时长**：约 30 秒
- **字幕**：要解说字幕
- **渲染路线**：确定性时间轴 HTML 场景 → 无头 Chrome 逐帧截图 → ffmpeg 合成

## 渲染管线

1. 编写 `index-trailer.html`：单场景、16:9、由单一时间轴 `t`（秒）驱动画面状态；URL 参数 `?t=<秒>` 可渲染精确帧（供截图）。
2. 用 headless Chrome 按 30fps 循环截帧（30 秒 × 30 = 900 帧），输出 1920×1080 PNG。
3. 用 ffmpeg 将帧序列合成为 `uno-trailer.mp4`（H.264，30fps，1080p）。
4. 校验输出（时长、分辨率、帧数）。

## 视觉风格

- 背景：奶油米色 `#F5F0EA`
- 主文字：深墨 `#1F1E1D`；次级：暖灰 `#6B675F`
- 强调：陶土色 `#D97757`（Claude 标志色），浅调 `#F0D9CE`
- 衬线标题（Georgia / Songti）+ 无衬线正文
- UNO 卡牌：CSS 复刻（红 `#E63946` / 绿 `#2A9D4B` / 蓝 `#2B6CB0` / 黄 `#F4B41A` 渐变），动作牌图标 ⊘/↻/+2/★/+4
- 字幕：画面底部居中，深色半透明底 + 白字，淡入淡出

## 场景布局

- 16:9 牌桌：中央弃牌堆（显示顶牌）+ 右侧抽牌堆；中央顶部当前颜色指示点
- 四座位：下方玩家、上/左/右 3 个 AI（显示剩余手牌数 + 卡背扇形）
- 当前行动者座位高亮描边
- 标题与字幕为叠加层

## 动画原则

- **确定性**：所有元素状态由 `render(t)` 直接计算（位置/透明度/内容），不使用依赖真实时间的 CSS transition/animation，保证 `?t=` 每帧精确可复现
- 事件之间用连续插值实现平滑移动（发牌飞入、出牌飞向弃牌堆、颜色切换）
- 局部动画（骰子、高亮脉冲）用正弦/三角波函数驱动，仍由 `t` 决定

## 故事板（30 秒，8 幕）

| 时间 | 画面 | 字幕 |
|------|------|------|
| 0–2.5s | 开场：四座位 + 牌桌淡入，标题「UNO 大作战」 | 纯浏览器里的 UNO |
| 2.5–5.5s | 每人飞入 7 张牌，翻开顶牌 | 每人发 7 张，翻开开局牌 |
| 6–8s | 玩家打红 7 到弃牌堆 | 出牌须同色或同数字 |
| 8–11s | AI 打绿 5 → 玩家打 Skip | 动作牌：跳过 · 反转 · +2 |
| 11.5–13.5s | 玩家打野牌 ★，颜色切换蓝色 | 野牌：自由选择颜色 |
| 14–18s | 打出「0」→ 触发闪电（掷双骰），AI 被罚抽 | 打出 0：随机触发小游戏！ |
| 19–21s | 玩家剩 1 张，亮出「UNO!」 | 剩一张：喊 UNO！ |
| 22–30s | 玩家打出最后一张获胜，计分 +「冲向 500 分」 | 先到 500 分获胜 · 打开就能玩 |
