# UNO 大作战 · 介绍 PPT 设计

日期：2026-07-31
状态：已获用户批准（方案 + 风格 + 结构）

## 目标

为浏览器版 UNO 游戏「UNO 大作战」制作一份介绍用的幻灯片（PPT），以 Claude / Anthropic 品牌美学为视觉风格。交付物为**单个自包含的 HTML 文件**，浏览器打开即可放映。

## 已确认的决策

- **交付格式**：HTML 幻灯片（单文件、零外部依赖，与游戏本身一致；支持键盘/点击翻页、打印导出 PDF）
- **内容重点**：玩法介绍 + 技术实现 + 特色机制（不单独做视觉截图展示）
- **篇幅**：标准版，约 12 页
- **语言**：中文

## 视觉风格（Claude 美学）

- 背景：奶油米色 `#F5F0EA`
- 文字：深墨色 `#1F1E1D`；次级文字用暖灰 `#6B675F` 类
- 主色（强调）：赭红/陶土色 `#D97757`（Claude 标志色），衍生浅调 `#F0D9CE` 用于底色块
- 辅助：柔和中性分割线（如 `#E6E1D8`）
- UNO 四色（红 `#E63946` / 绿 `#2A9D4B` / 蓝 `#2B6CB0` / 黄 `#F4B41A`）仅用于卡牌示意与色点点缀，不作为全局主色
- 排版：衬线标题（Georgia / 中文字体 Songti 类）呼应 Claude 的 Tiempos 编辑感；正文用系统无衬线栈
- 布局：大留白、细分割线、圆角卡片、克制的阴影；每页聚焦一个主题

## 交互与功能

- 键盘：`→` / `Space` 下一页，`←` 上一页，`Home`/`End` 跳转
- 点击页面右下角或点击翻页按钮前进
- 页码指示 + 总页数
- 支持打印（`@media print`）导出为 PDF
- 视觉上复刻少量 UNO 卡牌（CSS 绘制）作为插画，不使用任何图片资源
