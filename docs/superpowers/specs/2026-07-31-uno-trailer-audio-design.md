## 目标

为已完成的 `uno-trailer.mp4`（30 秒、1080p/30fps）配上完整音轨：中文解说、原创合成背景音乐、贴合画面的音效，输出带声音的最终版 MP4。

## 已确认的决策

- **解说**：macOS `say -v Tingting`（普通话）合成，9 句（开场 + 7 句字幕解说 + 结尾）
- **音乐**：原创程序合成（无版权风险），温暖轻快钢琴琶音，30 秒循环、首尾淡入淡出
- **音效**：程序合成（发牌轻响 / 出牌落牌 / 野牌魔法闪音 / 闪电雷声 / 骰子滚动+落定 / UNO 铃声 / 胜利号角）
- **工具**：纯 Python（`wave`+`math`+`array`，本机无 numpy）+ ffmpeg 混音合成
- **输出**：`uno-trailer-audio.mp4`（与无声版并存，不覆盖）

## 音乐设计

- 调式/和弦：C–Am–F–G（I–vi–IV–V），温暖明亮
- 织体：每和弦 8 拍分解琶音（八分音符，约 100 BPM），高八度点缀，衬低音根音
- 音色：正弦+少量泛音模拟钢琴/拨弦；音量中低（-18 dB 相对），给解说让位
- 0–1.5s 淡入，27.5–30s 淡出

## 合成与混音流程

1. **解说**：`say -v Tingting -o 句.wav --data-format=LEI16@22050` 逐句生成，ffprobe 测时长
2. **音乐/音效**：纯 Python 生成 WAV（采样率 44100，16-bit）
3. **混音**：ffmpeg 对每轨 `adelay` 定位 → `amix` 归一化合并（解说音量 1.0、音效 0.8、音乐 0.5）
4. **合成**：ffmpeg `-i uno-trailer.mp4 -i mix.wav -c:v copy -c:a aac` mux → `uno-trailer-audio.mp4`
