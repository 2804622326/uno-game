# UNO 大作战 · 介绍 PPT 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建一个单文件、零依赖、Claude 美学的 HTML 幻灯片，介绍「UNO 大作战」游戏——约 13 页，支持键盘/点击翻页、页码指示、打印导出 PDF。

**Architecture:** 单个 `index-presentation.html`，内含 `<style>` 定义设计令牌与版面，13 个 `<section class="slide">` 组织内容，`<script>` 实现导航与页码；UNO 卡牌示意全部用 CSS 绘制（`.mini-card`），不使用图片资源；`@media print` 每页一张幻灯片适配 PDF 导出。

**Tech Stack:** HTML5, CSS3, 原生 JavaScript，零外部依赖。设计规格见 `docs/superpowers/specs/2026-07-31-uno-ppt-design.md`。

- [ ] **Step 2: 追加 HTML 主体结构 + 导航脚本（先放空 slides，随后各 Task 填充）**

```html
<body>
<div class="progress"><i id="progBar"></i></div>
<main class="deck" id="deck">
  <!-- 各 Task 填充的 <section class="slide"> -->
</main>
<footer class="nav">
  <span id="pageNum">1 / 13</span>
  <span style="letter-spacing:.15em">← → 翻页 · Esc 全屏</span>
</footer>
<script>
  const slides=[...document.querySelectorAll('.slide')];
  let cur=0;
  function go(n){
    cur=Math.max(0,Math.min(slides.length-1,n));
    slides.forEach((s,i)=>s.classList.toggle('active',i===cur));
    document.getElementById('pageNum').textContent=(cur+1)+' / '+slides.length;
    document.getElementById('progBar').style.width=((cur+1)/slides.length*100)+'%';
  }
  document.addEventListener('keydown',e=>{
    if(e.key==='ArrowRight'||e.key===' '||e.key==='PageDown')go(cur+1);
    else if(e.key==='ArrowLeft'||e.key==='PageUp')go(cur-1);
    else if(e.key==='Home')go(0);
    else if(e.key==='End')go(slides.length-1);
    else if(e.key==='Escape'){
      if(!document.fullscreenElement)document.documentElement.requestFullscreen();
      else document.exitFullscreen();
    }
  });
  document.getElementById('deck').addEventListener('click',e=>{
    const r=e.currentTarget.getBoundingClientRect();
    if(e.clientX>r.left+r.width/2)go(cur+1);else go(cur-1);
  });
  go(0);
</script>
</body>
</html>
```
